# Aura

Musik-Wallpaper für Windows 10/11. Läuft hinter deinen Desktop-Icons, auf jedem Bildschirm,
mit Musikvideo, Songtexten, Uhr, leuchtendem Rand und Visualizer.

## Download

Rechts unter **Releases** die neueste `Aura-x.x.zip` laden, entpacken, `Aura.exe` starten.
Windows meckert beim ersten Mal, weil die App nicht signiert ist: "Weitere Informationen" → "Trotzdem ausführen".

Updates kommen danach von selbst, du musst nur auf "Jetzt updaten" klicken.

## Musik

- Song suchen und abspielen, direkt in Aura
- Spotify-Link (Song, Playlist, Album) reinkopieren, läuft ohne Spotify-App und ohne Login
- Läuft Musik woanders (Spotify-App, Browser, Deezer…), zeigt Aura sie trotzdem an
